# Consumer Spending during Unemployment: Positive and Normative Implications

**Ganong, Noel · 2019 · AER**
[↗ Full paper](https://doi.org/10.1257/aer.20170537)
**Section:** Insurance

## Abstract

Uses bank account transaction data to document that consumer spending drops sharply at UI benefit exhaustion — beyond what liquidity constraints alone predict. The pattern is consistent with present bias or reference dependence around the benefit level. Normative implication: optimal UI should taper benefits more gradually to smooth consumption over the unemployment spell.
