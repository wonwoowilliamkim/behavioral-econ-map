# Unemployment Insurance and Job Search Behavior

**Marinescu, Skandalis · 2021 · QJE**
[↗ Full paper](https://doi.org/10.1093/qje/qjab016)
**Section:** Insurance

## Abstract

Uses French job-board data linked to UI records to study how UI generosity affects search effort and match quality. Finds that UI reduces search intensity but increases the quality of job applications and accepted offers. Overall welfare effect is positive: the option value of better matching outweighs the moral hazard cost of reduced search effort.
