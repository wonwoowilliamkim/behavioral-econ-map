# The Value of Unemployment Insurance

**Landais, Spinnewijn · 2021 · REStud**
[↗ Full paper](https://doi.org/10.1093/restud/rdaa038)
**Section:** Insurance

## Abstract

Develops a revealed preference approach to measure the welfare value of UI using consumption and asset data. Constructs a sufficient statistic for the marginal value of UI that accounts for heterogeneity in liquidity constraints and risk preferences across workers. Finds the welfare value of UI substantially exceeds its fiscal cost for most worker types, justifying current generosity.
